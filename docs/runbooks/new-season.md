# Runbook — start a new season

1. Admin → Temporadas → "Nova temporada" (e.g. 2027–2028, Oct 1 → Apr 30). Mark it as current.
2. For each track (Alunos FRC, Alunos FTC, Mentores), add the phases, or use "Copiar da temporada anterior" and adjust the dates (FRC kickoff date!).
3. Check the "total esperado" preview for each track.
4. Admin → Convites: create multi-use invites for newcomers (e.g. "Alunos 2027", type student, 40 uses, 14 days). Share the links.
5. Deactivate members who left (Admin → Membros).
