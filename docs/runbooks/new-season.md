# Runbook — start a new season

1. **Admin → Temporadas → Nova temporada**: name (e.g. `2027–2028`), start Oct 1, end Apr 30.
2. Open it (**Configurar**). For each tab (**Alunos FRC**, **Alunos FTC**, **Mentores**), fill in the phases:
   - **Copiar da temporada anterior** brings last season's phases for that group with dates +1 year. Then adjust the FRC kickoff and build-season dates.
   - The first time, **Preencher com o modelo FRC** creates Pré-temporada 8 h, Build season 60 h and Competições 42 h per week. Adjust the dates.
   - **Copiar de …** copies another group's phases within the same season.
3. Check **Esperado na temporada** on each tab.
4. Click **Tornar atual**. "Minha presença" and the rankings switch to this season immediately.
5. Admin → Convites: create multi-use invites for newcomers (e.g. "Alunos 2027", type student, 40 uses, 14 days) and share the links.
6. Deactivate members who left (Admin → Membros).
