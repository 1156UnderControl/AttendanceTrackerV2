# Glossary (PT ↔ EN)

| Português (UI) | English (code) | Meaning |
|---|---|---|
| Membro | member | Student or mentor with an account |
| Aluno | student | `member_type = student` |
| Mentor | mentor | `member_type = mentor` |
| Categoria | category | `FRC` or `FTC` |
| Trilha / Grupo | track | Goal group: FRC students, FTC students, Mentors |
| Código de entrada | entrance code | 6-digit code typed at the kiosk |
| Quiosque | kiosk | The lab computer used for check-in |
| Entrada / Saída | check-in / check-out | Session start / end |
| Sessão | session | One check-in → check-out |
| Sessão pendente | auto-closed session | Closed by the daily 04:00 job, 0 h until corrected |
| Pedido de correção | correction request | Member asks to fix an auto-closed session |
| Temporada | season | E.g. "2026–2027", Oct → Apr |
| Fase | phase | Part of a season with expected h/week |
| Horas esperadas | expected hours | See attendance-math.md |
| Percentual de presença | attendance % | Worked ÷ expected |
| Convite | invite | Link that allows registration |
| Agora no lab | present now | Members with an open session |
